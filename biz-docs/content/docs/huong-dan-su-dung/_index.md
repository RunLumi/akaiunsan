# Hướng dẫn sử dụng dành cho khách hàng

Phần này viết bằng ngôn ngữ đời thường — bạn có thể gửi thẳng cho người dùng cuối.

1. [Đặt dịch vụ từng bước](/docs/huong-dan-su-dung/dat-dich-vu/)
2. Câu hỏi nhanh:

| Tôi muốn… | Làm thế nào |
|---|---|
| Đổi ngôn ngữ | Trang chủ → biểu tượng ngôn ngữ trên đầu trang → chọn VI/EN |
| Tìm đơn đã dùng | Tab **Booking** → chọn **History** |
| Thêm thẻ thanh toán | Tab **Account** → **Payment** → **Add** |
| Xem điểm thưởng | Trang chủ → số điểm cạnh tên của bạn |
| Tắt thông báo khuyến mãi | Liên hệ hỗ trợ (hiện tại theo chính sách vận hành) |
| Hủy một buổi đã đặt | Tab **Booking** → chọn đơn → nút hủy (chỉ với đơn chưa bắt đầu) |
