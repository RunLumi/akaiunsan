# Yêu cầu chức năng (Functional Requirements)

Mỗi yêu cầu chức năng (FR) có cấu trúc: **Mô tả → Điều kiện kích hoạt → Luồng chính → Tiêu chí chấp nhận**. Tiêu chí chấp nhận viết theo kiểu *khiểm thử được* (testable): tester có thể chuyển 1-1 thành test case.

Quy ước ưu tiên: **C** = Critical (chặn ra mắt), **H** = High, **M** = Medium.
