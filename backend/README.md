Ayasan api
    An api for various Ayasan's web projects.

Modules
- express
    Use this one to run web application.
- mysql
    Use it to connect with db.
- body-parser
    Use it as middleware to convert request parameters into a proper form we need.

Folder structure
    - controllers
        Actions of the app.
    - models
        Model/object of data.
    - routes
        Path of the app.
    *In some folder, there's index.js that use it as a whole group of same type.
    My idea is to not touch so much on app.js when need to update.
